# ai-first--k8s--otus
Учебный проект по развертыванию кластера, инфра компонентов k8s и приложения-примера, применяя Ai-first подход 

## ВАЖНО: В каталоге "./authentication--cloud-ru--for-api" созданы скрипты для получения доступа к учебному проекту в облаке "cloud.ru". В этм проекте должен быть развернут кластер kubernetes и приложение-пример.  

## В проекте используй 

# openspec (opsx\config.yaml)
# в терминале сначала запускай команду: wsl

  # Ключевые команды:
  # - преимущественно используй bash команды
  # - для обращения к API используй: curl или kubectl
  # - cloudlogin для получения токена доступа
  # - kubectl для управления кластером
  # - curl для прямых API-вызовов
