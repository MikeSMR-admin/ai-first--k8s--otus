# План обновления config.yaml с инструкциями из docs/cloud-ru

## Описание задачи

Добавить в файл `opsx/config.yaml` требование использовать в первую очередь инструкции из каталога `docs/cloud-ru` при исследовании, исполнении и других операциях с OpenSpec.

## Требование

При исследовании, исполнении и других операциях с OpenSpec использовать в первую очередь инструкции из каталога `docs/cloud-ru`. Этот каталог содержит официальную документацию cloud.ru по Managed Kubernetes и API.

## Основные документы для справки

### Быстрый старт и подключение
- `Быстрый старт k8s.md` — создание и подключение к кластеру
- `Подключиться к кластеру k8s.md` — настройка kubeconfig и cloudlogin

### Аутентификация и управление доступом
- `Аутентификация в API Managed Kubernetes.md` — получение токенов и ключей
- `Управление доступом в Managed Kubernetes.md` — RBAC и сервисные аккаунты
- `Создать сервисный аккаунт в cloud.ru.md` — создание и настройка SA
- `Просмотреть сервисный аккаунт в cloud.ru.md` — проверка SA через API

### Создание и управление ресурсами
- `Создать кластер k8s.md` — API-запросы для создания кластеров
- `Создать группу узлов k8s.md` — API-запросы для создания групп узлов

### Ограничения и особенности
- `Ограничения и особенности сервиса Managed Kubernetes.md` — квоты и лимиты
- `Версии k8s.md` — поддерживаемые версии Kubernetes

## Основные API эндпоинты

- IAM API: `https://iam.api.cloud.ru/api/v1/`
- Managed Kubernetes API: `https://mk8s.api.cloud.ru/v3/`

## Ключевые команды

- `cloudlogin` — для получения токена доступа
- `kubectl` — для управления кластером
- `curl` — для прямых API-вызовов

## Правила для открытого доступа

Всегда проверять актуальную документацию в `docs/cloud-ru` перед выполнением операций с OpenSpec.

## Файл для обновления

`opsx/config.yaml`

## Изменения

Добавить новый блок контекста в существующий `context` с описанием приоритета использования инструкций из `docs/cloud-ru` при работе с OpenSpec.
