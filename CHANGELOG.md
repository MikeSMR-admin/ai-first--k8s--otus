## Руководство по миграции

### С v0.0.1 на v0.1.0

1. **Обновите конфигурацию Terraform**
   ```bash
   cd infrastructure/terraform
   terraform init -upgrade
   terraform plan
   terraform apply
   ```

2. **Разверните Online Boutique**
   ```bash
   cd demo-apps/helm-chart
   helm install onlineboutique . -n online-boutique --create-namespace
   ```

3. **Проверьте развертывание**
   ```bash
   kubectl get pods -n online-boutique
   kubectl get nodes
   ```

## Примечания

- Этот проект использует экспериментальные функции из управляемого сервиса Kubernetes Cloud.ru
- Всегда делайте резервную копию файла `terraform.tfstate` перед применением изменений
- Используйте `env-example` в качестве справочника для создания вашего `terraform.tfvars`
- Для продакшен-развертываний используйте правильное управление секретами (HashiCorp Vault, Sealed Secrets)
